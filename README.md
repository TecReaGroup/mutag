# mutag

音频标签修改软件

## Introduction

## Project structure

```text
src/
  main/       Electron 主进程
  preload/    Electron preload API
  renderer/   React 渲染进程界面
  shared/     主进程和渲染进程共享的类型
```

## How to develop

```powershell
git clone https://github.com/TecReaGroup/mutag
cd mutag
npm install
npm run dev
```
